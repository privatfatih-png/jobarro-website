Privacy & Security

Your privacy is non-negotiable

Jobarro captures audio to help you in real time. Here's exactly what happens — and what doesn't.

No audio stored

Audio is streamed directly to Deepgram for real-time transcription and immediately discarded. Nothing is recorded or saved — ever.

Invisible at the OS level

The overlay uses a Windows system flag that excludes it from all screen capture. Zoom, Teams, and Meet cannot see it — technically impossible.

No account required

Activate with your license key and you're done. No sign-up, no profile, no cloud sync. Your data stays on your machine.

Encrypted in transit

All communication between Jobarro and our servers uses TLS encryption. Your API calls and responses are never exposed in plain text.

FAQ

Questions we get asked a lot

Still unsure? These are the questions most people ask before buying.

Will my interviewer know I'm using Jobarro? +
No. The Jobarro overlay is excluded from screen capture at the Windows OS level using a system flag. It is completely invisible in Zoom, Teams, Google Meet, and any other screen-sharing software. Your interviewer sees only your face and whatever you choose to share — never the overlay.
Does it work with Zoom, Teams, Google Meet, and WhatsApp? +
Yes, it works with all of them. Jobarro captures audio directly from your system output using Windows WASAPI loopback — it doesn't need to integrate with any specific app. Any call that plays audio through your speakers or headphones works automatically.
How fast does it actually respond? +
Typically under 1 second from the moment a question is spoken. Transcription uses Deepgram Nova-3 which processes speech in under 300ms, and Claude AI starts streaming the answer the moment a question is detected. You'll see the first bullet point appear while the interviewer is still finishing their sentence.
Is my audio or conversation stored anywhere? +
No. Audio is streamed in real time to Deepgram for transcription and immediately discarded. No audio, transcript, or conversation data is ever stored by Jobarro. We have a strict zero-retention policy — there is nothing to breach or subpoena.
Does it work on Mac? +
Jobarro is currently Windows 10/11 only. A Mac version is on the roadmap. If you'd like to be notified when it launches, email us at hello@jobarro.com and we'll add you to the early access list.
Can I cancel my subscription? +
Yes, anytime. Monthly and yearly subscribers can cancel at any time and retain access until the end of the current billing period. Lifetime licenses are a one-time purchase — no subscription, no recurring charges, yours forever.
Is it difficult to set up? +
Not at all. Download the installer, run it, enter your license key, choose your role and industry, and you're ready. The whole process takes under 2 minutes. No configuration, no drivers, no command line.
Does Jobarro work on Windows 11? +
Yes. Jobarro runs on Windows 10 (version 2004 or later) and all versions of Windows 11, including 23H2 and 24H2. It uses WASAPI loopback for audio capture and WDA_EXCLUDEFROMCAPTURE for the invisible overlay — both are core Windows APIs with full Windows 11 support. No compatibility issues have been reported.
Will proctoring or monitoring software detect Jobarro? +
It depends on the type of monitoring. Screen-capture-based proctoring (HireVue, Proctorio, Respondus) cannot see the Jobarro overlay — WDA_EXCLUDEFROMCAPTURE makes it invisible to any screen recording API at the OS level, the same mechanism Windows uses for DRM-protected video. Browser extension tools cannot see native Windows applications at all. However, if a platform explicitly monitors your running process list, Jobarro will appear like any other Windows application. We recommend reviewing the specific platform's terms before your interview.
